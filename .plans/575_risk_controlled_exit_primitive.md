## Goal

Ship `RiskControlledExit` — a generic, modelless dual-threshold compute-exit primitive: (1) upper threshold (stop-when-confident), (2) parametric lower threshold = squeezed-sigmoid confidence schedule `λ−(t) = σ(c(ωt − sB), l, u)` (stop-when-not-progressing), (3) an offline UCB/Hoeffding calibrator (`Risk̂ + √(log(1/δ)/2n) ≤ ε`) that turns a labeled validation set into guaranteed thresholds, (4) efficiency-loss selection among feasible (signal, threshold) pairs, (5) the App. C p_i ≥ p_c disarm tripwire. Consumers: MCTS termination, loop/speculative halting (Plan 304 fusion, Bebop Issue 023), riir-ai per-NPC deliberation (Research 339), riir-clippy fixpoint exit. **This is a UQ-bearing primitive — the exit-floor rule applies** (G2 must beat fixed-budget AND single-threshold floors at matched realized risk).

## Phase 1 — Core primitive (leaf-clean, modelless)

### Tasks

- [x] **T1.1** `risk_control_exit.rs`: `DualExitPolicy { lambda_plus, c, s, l, u }` + `fn exit(&self, s_tilde: f32, omega_t: u32, budget: u32) -> ExitVerdict {Continue, Commit, Abandon}` — 2 comparisons + 1 squeezed sigmoid (`σ(z,l,u) = (u−l)/(1+e^−z) + l`), zero-alloc, `#[inline]`. LANDED: `DualExitPolicy::{exit, lambda_minus}` + `ExitVerdict` (`#[repr(u8)]`) + `TerminalVerdict` (Commit/Abandon/Exhausted — the trace-level companion a whole-trajectory run needs) + `run_policy`. Mutual exclusivity enforced at construction (`0 ≤ l ≤ u < λ+` debug-assert). Measured **~4–5 ns/exit** (release, 10⁶ calls).
- [x] **T1.2** Shape helpers: `linear (s=0.5, cB≪1) / exponential (s>1) / log (s<0) / constant (c→0)` presets + doc table (paper Eq. 12–13). LANDED: `DualExitPolicy::{linear, exponential, log, constant}` (presets set `u = λ+/2`, keeping the invariant by construction); shapes pinned by 4 unit tests (convexity/concavity/flatness/monotone-rise) + the λ+ > λ−(t) ∀t dominance test.
- [x] **T1.3** Loss module: `fp_loss` (Eq. 8), `fn_farsighted_loss` (Eq. 9 — the future-correctness sum), `regret_loss` (Eq. 10), `past_wrongness` (Eq. 11); all bounded [0,1], pure fns over outcome slices. LANDED: `fp_loss` / `farsighted_loss` / `regret_loss` / `past_wrongness` as pure fns over `(&[bool], ExitTrace)`; Eq. 9 uses the inclusive future slice `[τ..T)` with denominator `T − τ` (the paper's `T−t+1` under 1-indexing). 4 unit tests incl. hand-computed fractions (2/6, 2/3, 2/5).
- [x] **T1.4** UCB calibrator: `calibrate(traj: &[(signal, outcome)], epsilon, delta, grid) -> CalibratedPolicy` — empirical risk + `sqrt(ln(1/delta)/(2n))` correction; `delta_over_grid` variant (δ/|G| multiple-comparison); refuse non-monotone risk-vs-hyperparam spans (monotonicity is ASSUMED by the paper — we verify empirically and fail loud). LANDED: `calibrate_into` (caller-owned `CalibrateScratch`, zero-alloc steady state) + allocating `calibrate` wrapper + `ucb_half_width` (local [0,1]-specialized one-liner citing the `hint_regret::hoeffding_half_width` neighbor — no feature dep) + `verify_monotone`/`MonotoneDir`/`MonotoneViolation` + `delta_over_grid` on `CalibrateConfig` (δ/(|G+|+|G−|), one union over both grids). Refusal = the span past the first violation is excluded from selection (trusted-prefix), reported in `CalibratedPolicy::{upper,lower}_monotonicity`; `verify_monotone` carries an explicit tolerance (default `0.5·ucb` — binomial noise scale). Infeasible grids fall back to the most conservative grid point with `fell_back = true` (told, not silently certified).
- [x] **T1.5** Two-step decoupled selection (`λ+` at ε+, then `{c,s,l}` at ε− conditioned) + efficiency-loss argmin among feasible pairs (Algorithm 1). LANDED: step 1 selects the SMALLEST feasible λ+ (most savings among certified); step 2 conditions on it and argmins **mean normalized compute** among FN-feasible schedules (the efficiency objective, documented; Eq. 10/11 losses remain exposed per-instance for consumers wanting them). Pinned by `two_step_interior_selection` (interior λ+ 0.85 chosen over equally-feasible 0.95; the steeper schedule chosen on compute) + the fallback test.
- [x] **T1.6** Runtime tripwire: `PiGePcMonitor` — rolling count of lower-exit wrongs vs rights; disarm lower threshold when p_i < p_c (App. C); upper-only mode remains guaranteed. LANDED: `PiGePcMonitor<const W: usize = 64>` fixed-capacity ring (zero heap, incremental counts, `min_n` sample floor) + `p_i`/`p_c`/`should_disarm`/`apply_guard` (Abandon → Continue while disarmed = the upper-only degradation). 3 unit tests incl. ring-eviction consistency and the `p_i == p_c` boundary (stays armed).
- [x] **T1.7** Unit tests: sigmoid schedule shapes pinned; exit verdict boundaries (λ+ > λ− invariant, mutual exclusivity); Hoeffding bound numerics; monotonicity refusal; tripwire disarm path. LANDED: **21 unit tests** in `#[cfg(test)] mod tests` (5 shape + 2 boundary + 4 loss + 1 run + 1 Hoeffding + 2 monotone/monotone-refusal + 2 calibrate-selection + 1 fallback + 3 tripwire + 1 scratch-reuse). Feature-on lib 1972 passed / 7 ignored.

## Phase 2 — GOAT gate (feature flag + bench + floors)

### Tasks

- [x] **T2.2** G1 risk-hold bench: synthetic confidence trajectories with known ground truth (solvable/unsolvable mixture); assert realized exit-risk ≤ ε across 40 validation/test resplits — AND show naive (no-correction) calibration violating the target on some resplits (reproduce paper Fig. 4 shape; if naive never violates at these n, record honestly and shrink n). LANDED: `g1_ucb_holds_naive_violates` — UCB **0/40 violations at both n=40 and n=400** (max realized risk 0.0100 / 0.0200 vs ε = 0.10); naive **7/40 violations at n=40** (0/40 at n=400). No shrink below 40 needed — 40 was already the violating regime. Honest mechanism split recorded: n=40 = 40/40 conservative fallbacks (the guarantee refusing; ucb 0.194 > ε), n=400 = 39/40 interior picks (genuinely certified adaptive selection, ucb 0.061).
- [x] **T2.3** G2 exit-floor bench (the floor rule): crowd-composition sweep 3:1 / 1:1 / 1:3 trivial:stuck — dual-exit vs (a) fixed-budget floor vs (b) single-threshold floor; plot correctness-vs-compute (paper Fig. 6 protocol); dual must win or tie each floor at matched risk and win overall (expect: matches paper — upper-only ≈ dual at 3:1, dual dominates at 1:1/1:3). FAIL → do not promote; record as refuted axis. LANDED: `g2_exit_floor_dual_wins_or_ties_both_floors` — dual compute **0.417** vs single **0.609** vs fixed **1.000** (mean over compositions); win-or-tie per composition per floor (accuracy identical across all three policies at every composition — realized FN ≈ 0 on this population; compute strictly less everywhere, strictly less than fixed by construction); Fig. 6 shape confirmed (dual-vs-single gap **0.075 → 0.189 → 0.310** as stuck share rises). Matched-risk construction: the single floor uses the SAME step-1 λ+ (same ε, same grids, same validation draw) — the comparison isolates the lower threshold. Full table in Bench 681.
